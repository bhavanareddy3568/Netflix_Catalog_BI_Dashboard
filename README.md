# 🎬 Netflix Content Analytics Dashboard

## 📌 Project Overview

This project analyzes Netflix’s content library using Excel, Power Query, Power Pivot, DAX, and Tableau Public to transform raw data into actionable business insights.

The project demonstrates an end-to-end analytics workflow, including data cleaning, data modeling, dashboard development, KPI creation, and interactive visualization.

The final solution consists of both an Excel Dashboard and an Interactive Tableau Public Dashboard that allow users to explore Netflix content trends across genres, countries, ratings, and content types.

----

## 🎯 Business Objective

Streaming platforms rely heavily on content strategy and audience engagement. This project aims to answer key business questions:

* How has Netflix’s content catalog evolved over time?
* Which countries contribute the most content?
* What genres dominate the platform?
* How is content distributed across audience ratings?
* What is the balance between Movies and TV Shows?
* What trends can be identified to support content strategy decisions?

----

## 📂 Dataset

### Source: Kaggle Netflix Titles Dataset

* Title
* Type (Movie / TV Show)
* Country
* Director
* Cast
* Genre
* Rating
* Release Year
* Date Added
* Duration

## 🏗️ Data Modeling

Created a relational data model using:

* netflix_titles
* netflix_titles_countries
* netflix_titles_category
* netflix_titles_directors
* netflix_titles_cast

Relationships were established using Show ID as the primary key.

This structure enabled accurate aggregation and prevented double-counting during analysis.

----

## 📊 Power Pivot & DAX

Developed analytical measures using DAX including:

* Total Titles
* Total Movies
* Total TV Shows
* Total Countries
* Total Genres

Used Power Pivot to support scalable reporting and dashboard development.

## 💡 Key Insights

### 📈 Content Growth

Netflix experienced rapid content expansion between 2016 and 2019, reflecting aggressive investment in content acquisition and production.

### 🎥 Content Mix

Movies account for a significantly larger portion of the Netflix catalog compared to TV Shows.

### 🌍 Geographic Reach

Content production is concentrated among a small number of leading countries, highlighting Netflix’s reliance on key production markets.

### 🎭 Genre Preferences

Certain genres consistently dominate the catalog, indicating strong audience demand and content strategy alignment.

### 🔞 Audience Targeting

Content ratings suggest a substantial focus on mature and young-adult audiences.
